How it works

  1. Type a title and your note, then press Save note.
  2. Every note is stored permanently in this app's cloud storage — close the tab and it will still be here next time.
  3. Notes appear newest first so your latest thought is always on top.
  4. Tap Delete on any note to remove it for good (you'll be asked to confirm).
